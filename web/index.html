Badge Studio Web

Programs a 44x11 LED name badge straight from the browser, over USB (WebHID) or Bluetooth (Web Bluetooth). Same glyphs and same wire format as the desktop app.

This browser cannot talk to the badge.

Not connected.

Bluetooth only: the badge stays silent while USB is plugged in. Unplug it, then press the first button until the Bluetooth icon appears. It leaves Bluetooth mode after every upload, so press the button again before each send. 


    
Also mirrored to the browser console, and readable as
      window.__badge.log / window.__badge.dump().
